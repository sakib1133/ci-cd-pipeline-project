# CI/CD Pipeline Project

A DevOps project demonstrating Continuous Integration and Continuous Deployment (CI/CD) using Jenkins, GitHub, Docker, and Linux environments. The project automates the build and deployment process for a web application.

---

## Features

- Automated CI/CD pipeline setup
- GitHub integration with Jenkins
- Docker-based application deployment
- Automatic build and deployment workflow
- Linux server environment
- Version control using Git and GitHub

---

## Technologies Used

- Jenkins
- Docker
- Git & GitHub
- Linux
- Node.js

---

## How to Run

1. Install Jenkins and Docker on a Linux system
2. Clone the repository
3. Configure Jenkins pipeline
4. Connect GitHub repository with Jenkins
5. Run the pipeline to automate build and deployment

---

## Learning Outcomes

- CI/CD workflow implementation
- Jenkins pipeline configuration
- Docker container deployment
- GitHub integration
- Linux server management
- DevOps automation basics
